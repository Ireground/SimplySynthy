# SimplySynthy

A very simple sketch synth (VST3) for starting ideas fast.

- **Oscillator:** Saw + Square levels, Pulse Width, Octave (−2…+2)
- **Unison:** 1–8 voices, Detune, Spread
- **Filter:** low-pass Cutoff, Resonance, Env Amt (follows the amp envelope)
- **Amp Env:** A / D / S / R
- **Delay:** tempo-synced ping-pong (1/16 … 1/2), Feedback, Mix
- **Reverb:** Size, Mix
- **Master:** Volume + meter, built-in soft clip and NaN guard
- 13 presets: Init + 3 Pads, 3 Plucks, 3 Leads, 3 Basses (click the preset name or use the arrows)
- 16-note polyphony, pitch bend ±2 semitones, resizable window (size is remembered)

Tips: double-click any control to reset it; hover a control to see its value in the screen.

## Get the plugin
Open the **Actions** tab → latest **Build SimplySynthy** run → download **SimplySynthy-VST3-Windows**,
unzip it and copy `SimplySynthy.vst3` to `C:\Program Files\Common Files\VST3`, then rescan in REAPER.
